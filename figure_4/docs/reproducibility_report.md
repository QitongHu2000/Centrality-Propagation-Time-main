## 输入与实现

八个真实网络统一为二值、无向、无自环的最大连通分量。生态网络保留权重大于0.1的边；原始数字节点 ID 排序后显式记录对应关系。karate 使用34节点、78边的二值图，stmarks 使用51节点、229边的无自环图。图3、5的四项网络统计直接由这些图计算，替代原网络信息表。有限时与稳态协议采用同一邻接和原始编号。 BA 图每个新节点连接3条边；WS 使用邻接度6和重连概率0.1。有限时大网络与稳态对照使用种子20260527，两个模型采用相同网络；耗时使用20260527、20260528、20260529三个种子。

`centrality.py` 和 `run_experiments.py` 维护11种比较方法。BC 排除路径端点并使用无向标准归一化；LPP 沿用用户已确认的实现，来源与公式核验范围见 `lpp_source_audit.md`。top-k 边界采用分数并列分配，分数容差为 `rtol=1e-10, atol=1e-12`；方法名次的能量容差为 `rtol=1e-8, atol=1e-10`。能量排除钳制源，并除以实际源位移的平方。 EC 与 PageRank 的迭代容差为 `1e-10`，最大迭代数为10000；PageRank 阻尼为0.9。这些实现设置留在复现说明，稿件仅保留有解释作用的方法参数。

PTC 动态规划与显式路径枚举在 NetworkX 图谱中全部142个2至6节点的连通非同构图上比较，使用四组指数，最大分数绝对误差为 `8.88e-16`。该检查验证实现等价性；动力学近似的适用条件仍见稿件第3.2节。算法拒绝非有限路径和；极端指数或长路径可能需要重标度或对数域累积。

稿件第2.3节定义非源扰动能量，第4.1.2节统一采用top-10、方法名次及相对最佳基线的增益。top-5%、全节点相关性和其他诊断仍可在本文件及结果中追溯。误差界与小指数展开的结论分别位于正文第3.2节和第3.3.1节，详细证明归入同一TeX的附录A；仿真使用完整PTC分数，未把小指数展开作为E/M数值近似，也未通过这些实验估计全路径截断误差。

## 稳态实验

八个真实图和 BA/WS 各100、500、1000节点，共14个网络，分别计算 E 和 M，共28组。E 使用 `B=1`，M 使用 `B=0.2,C=0.1`，相互作用强度为1。正平衡点全部稳定，最大向量场残差 `8.14e-11`。 线性稳态能量仍使用正文同一评价量：令 `K = (-J)^(-1)`，单源钳制的归一化响应为 `u_i^(m) = K_im / K_mm`，所以 `u_m^(m)=1`，非源能量为 `sum_{i != m} (u_i^(m))^2`。这里 J 是完整稳态 Jacobian；正文不另引入重复的能量指标。

正平衡点用阻尼不动点迭代求解，以相邻状态的最大差小于 `1e-12` 为停止条件。每个模型、每个真实图取排序数组的源索引0、`floor(N/2)`、`N-1`，各用1%和0.5%扰动，共96次独立非线性钳制平衡核验。E位移为该比例乘以 `min(x_m*,1-x_m*)`，M位移为该比例乘以 `x_m*`。最大能量相对误差1.86%，非源残差均小于 `1e-8`。

M 在两种选择规模下均14/14前三，E 为0/14。top-10 的 M/E 中位增益分别为 `+100.09%/-44.92%`，top-5% 为 `+254.19%/-40.99%`；M第一名数量分别为12/14和13/14。全节点 Spearman 中位相关分别为 E `-0.094`、M `-0.481`，与优质小组选择属于不同指标。原图7已移除；稿件第4.3.1节保留top-10的E/M前三计数和工作点解释；top-5%与详细统计保留在本说明和结果文件中；回复信仅使用当前正文已经报告的证据，完整数值保留在 `results/response_metrics.csv` 和 `results/mechanism/working_points.csv`。图4/6继续显示绝对终点能量。

保存的 E/M 行逐项保留其原始数值。筛选前的文件及 P 数值分析保存在 `PREV/snapshots/before_p_theory_only_20261010/code/results/`；`reports/provenance/response_metadata.json` 保留原筛选来源，原全局核验曾验证保留行与原始记录一致，并以当时实现重新计算28组线性响应。
